# 开发细节与算法实现

[使用手册](README.md) · [English](../en/development.md) · [项目首页](../../README.md)

本文说明 DichromaticMap 的数据组织、几何约定、数值算法及交互计算方式。
安装、功能入口和操作步骤见使用手册。

## 1. 模块与数据流

数值模块不依赖 Qt，界面负责组织参数、提交计算和绘图。

`CrystalGeometry` 保存同一晶格/晶轴可复用的几何量；`ProjectedGrain` 保存原子柱的
二维实际坐标 `positions`、轴向层号 `layers` 和参考晶格整数坐标 `half_indices`。
`StrainedCell` 保存两晶粒的整数胞矩阵、变形矩阵及共同胞基矢；`SelectedCellStrain`
另外保存均匀平移、四对实际顶点、极分解旋转及主伸长。
`PatternState` 持有一个窗口的物理和显示状态，`ComputeSession` 持有计算执行器和任务句柄。

## 2. 坐标与单位

以下公式把向量写为列向量；NumPy 点数组通常按行存储，因此代码中常以转置矩阵右乘。
长度使用参考晶格常数 a₀ 归一化，面积使用 a₀²；`half_indices` 的一个整数单位为 a₀/2。
显示旋转是最后施加的二维绘图变换，不改变原子模型、应变、层号或选区计数。

设约分后的整数观察轴为 **d**，`frame` 为正交矩阵 W，其三列为分析坐标轴
**e**ₓ、**e**ᵧ、**e**𝓏 在参考立方坐标中的表示，且 **e**𝓏 = **d**/‖**d**‖。
参考整数坐标 **h** 的三维分析坐标为 Wᵀ**h**/2。
程序利用叉积构造 **e**ₓ，再以 **e**ᵧ = **e**𝓏 × **e**ₓ 保证右手系。

两晶粒的参考面内转角分别为 φ₁ = +θ/2、φ₂ = −θ/2。
设 P 为二维原始平移基矩阵，**o**ₗ 为第 l 层的投影偏移，**n** 为二维整数坐标：

```text
x_g(n, l) = F_g R(φ_g) (P n + o_l) + t_g
x_view    = R(display_rotation) x_g
```

Fᵍ 作用于分析平面，随后施加均匀平移 **t**ᵍ；轴向不施加伸缩或剪切。
无论 Fᵍ 和 **t**ᵍ 如何变化，`half_indices` 始终保存原始晶格身份。
这使层归属、原子选择和参考晶格索引不依赖显示方向。

## 3. 整数晶格、平面基矢与轴向相位

实现见 [`get_geometry`、`plane_integer_basis`](../../src/dichromatic_map/crystal.py)。
SC、FCC 和 BCC 均表示每个原胞一个原子的 Bravais 点阵，数据模型没有额外的原子基元或化学元素数组。
输入晶轴除以三个指标的最大公约数，零向量被拒绝。下列矩阵以列存放原始 Bravais 平移，单位为 a₀/2：

```text
          [0 1 1]                 [2 0 1]              [2 0 0]
T_FCC  =  [1 0 1]       T_BCC  =   [0 2 1]     T_SC  =  [0 2 0]
          [1 1 0]                 [0 0 1]              [0 0 2]
```

令整数行向量 **r** = **d**ᵀT。连续两次扩展欧几里得算法构造整系数幺模矩阵 U，满足

```text
r U = (s, 0, 0),     s = gcd(r₁, r₂, r₃) > 0.
```

U 的后两列给出整数平面核：H = T U[:, 1:3]，因此 **d**ᵀH = 0。
第一列给出相邻轴向层之间的一步平移 **b** = T U[:, 0]。
整个构造在整数晶格上完成，不依赖从三维点云中估计平面周期。

最短平行于观察轴的晶格平移以 a₀/2 为单位写为 **a** = k**d**：

- FCC：**d** 的指标和为偶数时 k = 1，否则 k = 2。
- BCC：三个指标同奇偶时 k = 1，否则 k = 2。
- SC：k = 2，所有参考 `half_indices` 分量均为偶数，实际轴向平移为 a₀**d**。

于是一个轴向周期内的层数 N、轴向周期 L𝓏 和层间距 Δz 为：

```text
N  = k ||d||² / s
Lz = k ||d|| / 2
Δz = s / (2 ||d||)
```

对于 SC，约分后 gcd(**d**) = 1，所以 s = gcd(2**d**) = 2，
得到 N = ‖**d**‖²、L𝓏 = ‖**d**‖、Δz = 1/‖**d**‖（长度已用 a₀ 归一化）。
[100]、[110]、[111]、[112] 因而分别有 1、2、3、6 层。
SC 复用相同的整数平面构造、相位偏移和资源限制。

层号表示一个完整轴向周期内的离散高度相位，不是可任意合并的二维投影类别。
不同层即使投影接近，也不会参与同层重合或局部配对。

程序对 H 执行二维 Gauss 约化：交换长短基矢，并从第二基矢减去第一基矢的最近整数倍。
再调整取向，使投影基矩阵 P = W[:, :2]ᵀH/2 的行列式为正。
第 l 层从 l**b** 出发，减去整数平面平移，把投影偏移收回原始平行四边形。
这种处理保留精确的轴向高度及晶格身份，同时缩短枚举坐标范围。

几何结果通过最多 64 项的 LRU 缓存复用，返回的几何数组设为只读。
当前交互限制为约分后轴指标绝对值不超过 64、轴向层数不超过 256。

### 固定倾转轴的错取向角范围

参考角输入使用未变形立方点阵的对称性。SC、FCC、BCC 具有相同的立方纯旋转点群，
即行列式为 +1 的 24 个带符号置换矩阵。对于约分后的整数轴 **d**，
用整数运算统计满足 S**d** = **d** 的矩阵数 n，得到保持有向晶轴不变的旋转子群阶数。
使 **d** 变成 −**d** 的操作不计入绕 **d** 的旋转。

```text
绕轴旋转周期 = 360° / n
角度输入范围 = [0°, 180° / n]
```

输入范围进一步利用交换两晶粒后的 θ 与 −θ 等价关系。
⟨100⟩、⟨110⟩、⟨111⟩ 的阶数分别为 4、2、3，所以上限分别为 45°、90°、60°。
其他立方晶轴（包括 ⟨112⟩）的阶数为 1，上限为 180°。
立方晶体旋转轴的阶数可参见
[IUCr 教学手册 *Projections of cubic crystals*](https://www.iucr.org/what-we-do/education/pamphlets/projections-of-cubic-crystals)。
自定义晶轴先经过整数解析和约分，再做对称性计算，因此负指标、整数倍指标及分量置换
无需依赖菜单名称分类。

该约化保持所选倾转轴，不是允许改变晶轴表示的全局立方最小错取向角搜索。
当前支持的有效立方晶轴都能算出阶数。若无法获得晶体对称性信息，则采用 0–180°
通用范围。公开函数 `misorientation_range(axis="110", lattice="FCC")` 返回不可变的
`AngleRange(maximum_deg, period_deg, symmetry_order)`；未知点阵返回
`(180.0, None, None)`，不假定已知旋转周期。晶轴仍需通过有效性验证，
实际几何构造仍拒绝不支持的点阵。

GUI 数值框、滑块、范围提示及 CSL 预设列表共享同一上限。
命令行角度验证在超限时报告错误，不自动折叠为对称等价角。
底层数值几何和旋转函数仍按传入角度计算，不施加 GUI 的输入限制。

CSL 菜单由整数四元数 (m, n**d**) 构造，角度为 2 atan2(n‖**d**‖, m)，
互素四元数的预设 Σ 为 m² + n²‖**d**‖² 的奇数部分。
[100]、[110] 使用选定条目，其他轴使用有限的低 Σ 搜索；所有菜单都只保留当前角度范围内的项。
例如 [100] 的 Σ5 保留约 36.87°，其互余角 53.13° 超出 0–45° 范围。
菜单名称与显示角度匹配容差不用于证明精确共同胞的公度性。

## 4. 按视野逐层枚举原子柱

实现见 [`projected_columns`](../../src/dichromatic_map/crystal.py)。
每层原子构成二维整数网格，因此无需构造完整三维块体再投影。
给定视野矩形、Fᵍ、R(φᵍ) 和 **t**ᵍ，程序按以下步骤生成原子柱：

1. 计算实际投影基矩阵 B = FᵍR(φᵍ)P 及该层实际偏移 **c**ₗ。
2. 将矩形四角通过 B⁻¹(**x** − **c**ₗ) 逆投影到整数坐标空间。
3. 对各坐标的极值取整，并各扩展一格，得到覆盖视野的整数枚举范围。
4. 直接填充最终整数坐标数组，计算实际位置 B**n** + **c**ₗ。
5. 以原视野矩形再次裁剪，并保留微小浮点边界裕量。
6. 用 H**n** + **h**ₗ 生成参考 `half_indices`，与位置和层号一起返回。

计算量主要随二维覆盖面积及层数增长。旋转或剪切会扩大逆投影的整数包围框，
因此候选数量通常多于最后保留的原子柱数量。
资源限制针对每个晶粒、各层累计的 **250,000 个候选柱**，不是最终可见原子数。
超限会终止本次枚举并报告原因；手动胞计数也使用同一个保护机制。

## 5. 重合点检测与精确共同胞

这两项功能分别回答「当前构型哪些位置重合」和「参考晶格是否存在可识别的共同平移」。
实现均在 [`matching.py`](../../src/dichromatic_map/matching.py)。

### 5.1 当前原子位置的同层重合检测

`same_layer_coincidence_sites` 在每一轴向层内独立处理两晶粒的位置。
界面使用 ε = 10⁻⁶ a₀，把第二晶粒坐标按 `floor(position / ε)` 分箱，
将每个二维箱坐标的两个 32 位部分打包为一个可排序整数键。
对第一晶粒每个未匹配点，在本箱和八个邻箱中批量二分查找，再以实际欧氏距离 ≤ ε 验证。
输出位置为两个端点的中点，用于绘制重合标记。

「精确」在这里指给定数值容差内的坐标重合；这一检测也适用于已经施加均匀变形的原子。
有限视野中的重合点本身不证明全局周期性，也不能单独确定 Σ。

此散列实现针对极小容差下、一个箱内至多一个晶格点的工作条件。
每个键只尝试排序后的首个候选，且键保留的是各坐标的低 32 位；实际距离复核可以
拒绝错误候选，但不能使键冲突或多点占箱的查询变成穷尽搜索。
因此它不应被当作任意尺度、任意点云的通用半径匹配器；较大半径的局部匹配使用下面的独立实现。

### 5.2 从有理旋转构造共同胞

`exact_csl_cell` 先识别下式中的有理数 n/m：

```text
tan(θ / 2) / ||d|| = n / m.
```

参数 `max_denominator` 同时限制约分后互素系数 m、n 的上限（默认为 128），
避免接近 180° 时出现过大的分子。重建角度与输入角度须相差不超过 10⁻⁹ 度。
未识别的角度返回 `None`；即使数学上存在共同胞，所需系数超出上限时仍可能无法识别。
支持完整的 0–180° 区间：0° 和 180° 分别使用精确端点四元数 (1, **0**) 与
(0, **d**)，避免在 180° 计算奇异的正切函数。

通过整数四元数 (m, n**d**) 构造三维有理旋转。其分子矩阵及分母为：

```text
A = (m² − n²||d||²) I + 2n² d dᵀ + 2mn [d]×
D = m² + n²||d||².
```

程序选取 H 中绝对行列式最大的二维子块，以整数伴随矩阵把该旋转表达为平面有理矩阵 Pᵣ/dᵣ，
满足 B₂⁻¹B₁ = Pᵣ/dᵣ，其中 Bᵍ = R(φᵍ)P。
随后求整数同余核

```text
P_r n ≡ 0 (mod d_r),
```

得到共同平移的整数基 M₁，并令 M₂ = PᵣM₁/dᵣ。
`congruence_kernel` 逐行使用扩展欧几里得变换及最大公约数收紧整数核，
无需假设某个系数在模 dᵣ 下可逆。
最后对 B₁M₁、M₁、M₂同步进行 Gauss 约化，并验证两晶粒胞矢量在 10⁻⁸ a₀ 内一致。

该结果是保持参考层相位的平面共同平移胞，不保证是完整三维 CSL 的原始胞。
预设中的 Σ 来自原始整数四元数范数去除因子 2 后的奇数部分，
不能用屏幕重合点数、手动选区计数或上述平面胞原子数直接替代。

## 6. 局部互为最近邻匹配

实现见 [`_nearest_in_radius`、`local_near_pairs`](../../src/dichromatic_map/matching.py)。
距离阈值 r 的允许范围为 (0, 0.5] a₀，默认 0.05 a₀；它是原子间距阈值。
每层分别计算 G1→G2 和 G2→G1 的半径内最近邻，只保留双向选择一致的配对。
这保证每个端点最多参与一对，不等价于最大配对数量或总距离最小的全局匹配。

空间箱边长取 r，查找九个邻箱即可覆盖半径 r 内的点。
实现先减去共享坐标原点，再给箱坐标矩形增加边界填充，构造无混叠标量键：

```text
key(cx, cy) = cx * stride + cy + stride + 1.
```

在确认整个键范围适合 `int64` 后使用该快速路径；否则回退到两个完整 `int64` 坐标的结构化键。
排序后记录各非空箱的起点和占用数，每次箱查询只需一次二分查找，
随后检查箱内的所有原子。查询点按最多 8,192 个一批处理，不建立全原子两两距离矩阵。

完全等距时按目标端点的坐标字典序选择，使结果不依赖输入遍历顺序或任务完成顺序。
精确重合对也参与最近邻选择，之后才从局部叠加层中排除，避免同一端点另外配到近邻。
返回对象保留两个原始端点；紫色中点和连线只是它们的显示表示，不移动原子。

## 7. 自动均匀应变与周期胞搜索

实现见 [`candidate_vectors`、`solve_cells_chunk`、`pareto_cells`](../../src/dichromatic_map/strain.py)。
目标是在有限整数范围内寻找 M₁、M₂ 和对称正定变形 F₁、F₂，使

```text
F₁ B₁ M₁ = F₂ B₂ M₂ = C.
```

自动方法使用 Fᵍ = I + Sᵍ，Sᵍ 对称，不加入额外刚体旋转。
输入主应变上限 e = percent/100；当前允许 percent ∈ (0, 10]，整数搜索上限为 2–40。

### 7.1 候选向量与必要条件

第一晶粒枚举半平面的非零整数向量，去掉 ±**n** 的重复表示。
将对应实际向量 **v** 转到第二晶粒基坐标，并在附近的整数偏移中寻找 **w**。
若两晶粒变形的谱范数偏离单位阵都不超过 e，则共同向量必须满足：

```text
||v − w|| ≤ e (||v|| + ||w||)
||v − w|| ≤ 2e ||v|| / (1 − e).
```

程序用 B₂⁻¹ 的算子范数确定整数邻域半径，用各行范数进一步收紧逐坐标边界，
然后计算实际相对误差。这样避免构造所有整数向量间的完整距离矩阵。
候选最多保留 320 对：长度和最小的 160 对与相对误差最小的 160 对取并集。

把两对候选组成胞矩阵时，先排除零面积及取向不一致的组合。
对两条胞对角线 **a**₁ ± **a**₂ 也检查上述必要条件，并保留浮点裕量，
让不可能满足应变上限的胞在矩阵求解前退出。

### 7.2 最小范数求解与接受条件

每个晶粒以 `[Sxx, Syy, √2 Sxy]` 为三个未知量，
它们的欧氏范数平方正好等于 ‖Sᵍ‖²_F。
共同胞的两个二维边矢量给出四个约束，组成 4×6 线性系统。
通过基于 SVD 的伪逆 `pinv(..., rcond=1e-11)` 求最小范数解，最小化
‖F₁−I‖²_F + ‖F₂−I‖²_F。

这是先求最小改变量解、再检查限制的过程。接受条件为：

- F₁、F₂ 的全部特征值为正；由于矩阵对称正定，它们就是主伸长。
- 最大 |主伸长 − 1| 不超过 e 加 10⁻¹² 数值裕量。
- 两晶粒共同胞矩阵的最大分量残差小于 10⁻⁸ a₀。

接受后对共同胞和两套整数胞矩阵同步约化。
胞大小指标是每晶粒一个完整轴向周期中的参考原子数 N|det Mᵍ|。
结果按两晶粒原子数之和与最大主应变筛选 Pareto 折中，去除重复项，最多返回 12 个。

整数范围、候选截断及求解后的上限检查都使此搜索具有明确的范围限制。
未返回结果不表示所有周期胞均不可行；返回结果也不是全局最小胞、全局最小应变或弹性能最优证明。

## 8. 所选四对顶点的均匀对齐

实现见 [`strain_selected_cell`](../../src/dichromatic_map/strain.py)。
输入为两个晶粒各四个实际原子位置，形状为 `(2, 4, 2)`。
两个四边形均须凸、不自交且非退化，并属于同一选定轴向层。
程序扣除该层基坐标相位，把每个顶点逆变换到晶格整数坐标，
要求回到实际坐标后的误差不超过 10⁻⁷ a₀；两胞的整数边矩阵也须取向一致。

先分别扣除两组顶点质心 **c**₁、**c**₂，得到中心化顶点 **a**ᵢ、**b**ᵢ，求解

```text
min  ||F₁ − I||²_F + ||F₂ − I||²_F
s.t. F₁ a_i = F₂ b_i,    i = 1, 2, 3, 4.
```

允许旋转时，两个一般 2×2 矩阵合计八个增量未知量，四对顶点给出八个方程。
旋转上限为 0 时改用两个对称矩阵的六个未知量，并采用与自动搜索相同的 √2 权重。
两种情况均使用 `lstsq(..., rcond=1e-11)`；不忽略第四对顶点。

对一般 Fᵍ 用 SVD 构造极分解 Fᵍ = RᵍUᵍ。
主应变是奇异值减 1，刚体旋转角从 Rᵍ 单独读取，不能用一般非对称 Fᵍ 的特征值代替。
默认主应变上限为 2%，每晶粒旋转上限为 1°；旋转上限允许 0–5°。
在求解后检查塌缩、反射和两项上限，而不是在上限约束内搜索全部可行变换。

均匀平移取为

```text
t_g = (c₁ + c₂) / 2 − F_g c_g,
```

使两组变形后的质心位于原质心的中点。
最终独立检查四对顶点最大欧氏距离和两条共同边的分量残差，均要求不超过 10⁻⁸ a₀。
因此非原点选区和非 A 层的共同胞也能在实际空间正确对齐。

成功后对整个晶粒施加同一个 Fᵍ 和 **t**ᵍ，重新生成晶格并逐层检测重合。
共同胞定位在变形后的首个顶点，不能假定原点仍为零，也不保证所得胞为最小胞。
参考错取向角 θ 保留不变；极分解框架中的相对角为 θ + rotation(G1) − rotation(G2)。

`strain_tensors` 计算 Green–Lagrange 张量 E = (FᵀF − I)/2，
并转回各晶粒原始立方框架。它与「主伸长减 1」是不同的应变量定义。
这些算法求解几何兼容性，不包含材料弹性常数、能量、应力或原子弛豫。

## 9. 完整选区计数与三维向量

### 9.1 同层凸四边形计数

实现见 [`count_cell_atoms`、`cell_membership`](../../src/dichromatic_map/cells.py)。
每个晶粒使用自己四个真实顶点构成的多边形，分别计算面积和计数。
计数重新枚举完整多边形包围框的所有层原子，随后先筛选顶点所属层，再做边界和角点计算。
因此结果不依赖当前视野、绘图缓存或 Layers 显示开关。
数值接口允许 `layer=-1` 统计全部轴向层，界面传入的是所选顶点的实际层号。

凸多边形成员判定使用各有向边与「顶点到点」向量的叉积，除以边长得到有符号距离。
容差随最大边长缩放，分别得到严格内部和边界集合。
若四点满足平行四边形条件，再计算基坐标：

```text
p = p₀ + u(p₁ − p₀) + v(p₃ − p₀),     0 ≤ u,v < 1.
```

半开计数保留两条下界边、排除两条上界边，避免周期平铺时重复计数。
数值实现把物理边界容差换算到 u/v 坐标，使用 −ε ≤ u,v < 1−ε；
每个保留原子计为 1，不给闭合边和角点额外分配分数权重。
输出另外区分半开集合中的边原子和角点；它们不同于闭合边界上的全部原子。
一般凸四边形只提供内部、边界及闭合计数，几何平行四边形本身不证明晶格周期性。

可选 GB 过滤由有向参考线的叉积符号决定，每个晶粒分别应用其左右侧开关。
面积用相对首顶点的坐标计算鞋带公式，降低大幅平移时的数值抵消。
超出枚举限制时返回错误，不报告不完整计数。

### 9.2 一个实际向量的两种晶粒表示

实现见 [`crystal_vector_coordinates`](../../src/dichromatic_map/crystal.py) 和
[`_selected_vector_displacement`](../../src/dichromatic_map/ui/window.py)。
实际归一化位移 **d**ₐ 的 x/y 分量来自两个当前原子位置之差；
z 分量来自两端 `half_indices` 的轴向投影，并加上 P2 所选轴向周期像。
该周期像由整数参数指定，不自动选择最短距离的周期像。
跨晶粒时只能用参考指标差求共享轴向的 z 分量，x/y 必须使用各自变形和平移后的实际位置。

设 Qᵍ = R₃(φᵍ)Wᵀ 把参考立方坐标映射到分析坐标，
F₃ᵍ 把面内变形扩展到三维且保持轴向不变。定义

```text
B_g = F3_g Q_g
O_g = polar_rotation(F3_g) Q_g
current = O_gᵀ d_a
lattice = solve(B_g, d_a).
```

`current` 是跟随极分解旋转的正交立方框架中的实际向量分量；
`lattice` 是同一向量在变形后的常规晶格基矢中的系数。
这里 **d**ₐ 已用 a₀ 归一化，公式无需再次除以 a₀，也不再次对位移施加变形。
这些表示描述直接晶格方向 `[uvw]`，不计算倒易晶面指标 `(hkl)`。

简单有理分量仅在全部分量误差 ≤10⁻¹⁰、公共分母 ≤48、约分后方向指标绝对值 ≤256 时
格式化为保留长度的整数/分数方向；否则显示近似实数分量。

## 10. 绘图缓存、拾取与后台调度

实现见 [`ui/plot.py`](../../src/dichromatic_map/ui/plot.py)、
[`ui/window.py`](../../src/dichromatic_map/ui/window.py) 和 [`compute.py`](../../src/dichromatic_map/compute.py)。

原子生成区通常覆盖模型视野宽高的两倍；视野接近缓冲边界时才重新生成。
局部互为最近邻查询还需两次半径查询的外部数据，因此视野周围保留至少 2r 的邻域，
并排除缺少该邻域的缓冲区边缘配对。
显示旋转后的视野会先转回模型坐标，再求包围框，保证枚举覆盖当前画面。

悬浮晶粒参考轴使用 `geometry.frame[:, :2]` 的两个横向单位方向，以晶体方向 `[uvw]` 标注。
二者既垂直于观察轴，也相互垂直；[110] 观察轴对应的方向平行于 `[-1 1 0]` 和 `[0 0 1]`。
`in_plane_reference_directions` 通过整数叉积和最大公约数约分生成带符号的标签，
标签表示方向，不指定原始平移的长度。`in_plane_reference_axes` 中，二者在参考分析平面的
归一化分量就是两个单位基矢。晶粒 g 的显示方向为：

```text
v_g,i = R_display R_polar(F_g) R(φ_g) e_i
φ₁ = +θ/2,    φ₂ = −θ/2,    i = 1, 2.
```

这里只使用 Fᵍ 的极分解旋转，因而保持两箭头正交；若直接使用 Fᵍ，得到的是剪切或拉伸后的
晶格方向，与此处的取向参考不同。参考轴锚定在视野左下角，以固定屏幕尺寸绘制，
不依赖模型原点或原子位置。两晶粒共用一个固定原点，以所选晶粒颜色区分（默认蓝色和橙色），
不绘制 G1/G2 标题。
布局为箭头和 `[uvw]` 标签预留与当前转角无关的空间，因此旋转不会使面板重新居中或改变尺寸；
平移和缩放也保持其位置与尺寸。晶体几何、参考角、变形的极分解旋转和显示旋转决定参考轴方向。
`Grain reference axes` 控制显隐，可见时向量读数为其预留空间并显示在上方；导出包含启用的参考轴。

平移时复用散点数据，仅更新视野内统计和相关标注；标记直径实际变化时才调用尺寸更新。
局部叠加层缓存配对中点、距离和连线，缓存键包含显示旋转、可见层、GB 过滤、
几何状态、缓冲边界及距离阈值。原子对对象或这些条件变化时重新提交绘图数据。
可见原子数直接使用已变换、已过滤的散点坐标，避免重复旋转全部原子。

拾取先将鼠标位置转回模型坐标，只查询当前可见原子，并在像素坐标中比较距离。
模型几何签名不匹配时暂不接受旧原子的拾取。
手动胞顶点保留两个晶粒的真实端点及层号，配对中点仅用于确定点击对象。

计算执行器与窗口共享：多 worker 使用 `spawn` 进程池，单 worker 的局部配对、
手动计数和自动搜索使用后台线程；单 worker 的晶格生成与精确重合检测走同步路径。
所选四对顶点的矩阵拟合规模很小，直接同步执行。
逐层任务按层组提交，避免每个层都传递一次完整原子数组。
如果存在 `threadpoolctl`，进程初始化将内部 BLAS 线程数限制为 1，减少嵌套并行。

`NearSearch` 把准备阶段与胞求解阶段分开，求解任务每次处理上三角候选对的八行，
只构造该任务负责的索引，并限制同时在途的任务数。
新请求增加代号并清理等待队列；已经开始的有限任务可继续结束，但旧代号结果不发布。
结果按块起始行顺序合并后再做 Pareto 筛选，使等价候选的保留顺序不受进程完成顺序影响。

晶格重建、匹配和手动计数也会核对当前几何参数、距离阈值或计数键。
显示旋转、平移和缩放不会修改已有物理结果；改变晶格、参考角或实际变形时，
相关选择与缓存按依赖关系失效。耗时任务在界面事件循环中轮询完成状态，结果通过当前请求校验后更新。

## 外观状态与符号绘制

`PatternState.grain_colors` 保存两个 `#RRGGBB` 字符串，`layer_symbols` 为每个轴向层保存一个唯一符号标识，
同一层在两晶粒中共用该标识。不依赖 Qt 的 `appearance.py` 校验颜色格式并规范化为小写，
同时检查符号数量、合法性和唯一性；两晶粒颜色可以相同。前 12 层沿用原有 PyQtGraph 符号，
后续层默认使用 `number:13` 至 `number:256`。`number:1` 至 `number:256` 都是稳定标识，
合法性不取决于当前层数，因此减少层数不会丢弃仍保留层上已选择的高编号符号。
层数调整保留已有合法分配，新层从尚未占用的默认符号中补齐。

`ui/markers.py` 将普通标识解析成内置符号，将编号标识解析成带数字镂空的圆形 `QPainterPath`，
并缓存路径，不修改 PyQtGraph 的全局符号注册表。数字使用内置七段式矢量轮廓，不依赖系统字体，
避免无可用字体的 Qt 离屏环境将不同编号变成相同的缺字方框。绘图区和控件图标共用此解析器。
晶粒颜色同时用于参考轴、手动胞轮廓和图例；G1 保持实心和较深的边缘，G2 保持空心轮廓。

`APPEARANCE` 控件禁用其他层已占用的符号，回调也拒绝重复分配。修改外观只重绘已有数据并刷新相关图标和叠加层，
不会使物理几何、配对或计数结果失效，不提交数值任务，也不清除选点、应变或平移。
`Reset appearance` 仅恢复这些样式设置。

## 会话保存、恢复与数值导出

`session.py` 将 `.dmap` 定义为格式版本 2 的 ZIP 文件。`session.json` 显式保存物理和显示输入，
不直接序列化整个 `PatternState`。当前晶格、晶轴和角度覆盖可能过时的启动参数，数组转换成 JSON 列表，
所选原子保留晶粒、轴向层及整数半坐标。已应用的 `StrainedCell`、`SelectedCellStrain` 同时保存
撤销所选胞应变所需的原始顶点与局部配对阈值；交互模式和未完成选点也会保存。
绘图缓存、任务句柄、worker 数量及本地路径不写入文件；自动搜索仅保存已应用的候选胞。
版本 2 在状态字段中新增 `grain_colors` 和 `layer_symbols`。版本 1 文件仍可加载，自动使用默认颜色和唯一层符号，
再次保存时写出版本 2；不支持的后续版本和未定义字段会被拒绝。

`load_session` 返回 `SessionSnapshot(state, settings, view_range)`。加载时检查格式版本、成员名称与
大小限制、有限数值、数组形状、晶轴/层/整数指标、颜色格式与符号唯一性、变形方向、共同胞一致性及原子的实际位置。
直接从压缩包读取 JSON，不解压文件、不使用 pickle；CSV 只是导出结果，不参与恢复。
`save_session` 先验证将写出的状态并生成数值表，再在目标目录写临时文件，完成后刷新并原子替换目标。
失败保留原文件，临时文件会清理。

`SessionController` 替换窗口状态前先检查视野枚举上限，然后停止旧定时器，使几何/搜索任务失效，
并移除旧计数 future 的结果发布入口。应用状态时阻断控件信号，防止切换晶轴等回调清除已导入的选点。
随后按恢复的输入重新生成图形、局部配对及手动计数，沿用当前窗口的 worker 设置。
保存的视野使用显示坐标；窗口宽高比不同时，等比例约束可能扩展视野，但保持中心和晶格比例。

`exports.build_export_tables` 生成 UTF-8 CSV 文本及 `README.txt`：

- 计数使用各晶粒的实际多边形和选定层，调用 `count_cell_atoms` 重新计算，仅在启用时应用 GB 两侧筛选。
  不使用缓存或当前视野计数；不可用的半开计数写为空白。
- 向量 xy 分量来自真实端点位置；轴向分量来自整数半坐标差及所选周期像。
  将同一物理位移分别换算到分析/显示、极分解刚体旋转后的立方坐标及变形晶格坐标；跨晶粒测量使用两套晶粒坐标。
- 应变表使用当前两晶粒的 F 与平移，通过 SVD 得到 `F = R U`，并导出 `E = (F.T F - I)/2`
  在参考分析平面及参考立方坐标中的分量。刚体旋转与主工程应变分别记录。

浮点数保留 17 位有效数字，表格明确标注单位与坐标系；a₀/Å、a₀²/Å² 换算使用保存的晶格常数。
手动胞或向量尚未选完时，对应表只有表头；未应变状态的 F 为单位矩阵、E 为零。
数值导出失败会中止保存，不写出部分或过期结果。
