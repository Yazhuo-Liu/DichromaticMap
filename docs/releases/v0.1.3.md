# DichromaticMap v0.1.3

DichromaticMap 0.1.3 adds simple-cubic support, restorable sessions with
numerical exports, and customizable plot appearance.

## New features

- **Simple cubic (SC)** support alongside FCC and BCC in the numerical library
  and viewer, including custom integer viewing axes.
- **Grain reference axes:** four crystallographic direction arrows, sharing a
  stable origin and using the two grain colors. Enabled by default and
  toggleable in `VIEW`.
- **Axis-dependent misorientation ranges:** 0–45° for ⟨100⟩, 0–90° for ⟨110⟩,
  0–60° for ⟨111⟩, and 0–180° for other cubic axes. Custom integer axes use
  the same cubic-symmetry calculation.
- **Session saving and restoration:** use `Save session…` beside `Export PNG…`
  and `Import session…` in `ORIENTATION` to retain crystal settings, selected
  points, applied strain and translations, visibility, appearance and view.
- **Numerical exports:** each `.dmap` session is a ZIP archive containing
  `counts.csv`, `vectors.csv` and `strain.csv`, alongside its saved state.
  Counts describe the selected-layer manual cell; available table rows depend
  on the current selections and applied results.
- **Appearance controls:** choose G1/G2 colors and unique layer symbols in
  `VIEW / PERFORMANCE → APPEARANCE`. Additional layers use numbered circles;
  `Reset appearance` restores the defaults. Styles are saved in sessions and
  used in PNG exports.

## Improvements and fixes

- Numbered markers remain distinct in Windows and headless Qt environments
  without relying on system fonts.
- Improved control layouts for small windows and different font metrics.
- Added space between the controls and plot, and fixed plot-border clipping
  when resizing the window.
- Renamed the orientation label to `View axis`.
- Updated English and Chinese documentation and expanded regression coverage.

## Compatibility

- Python 3.10 or later is required. The viewer uses PySide6 and PyQtGraph.
- GUI and command-line angle inputs now follow the axis-dependent ranges.
  Out-of-range `--angle` values are rejected rather than automatically converted.
- New sessions use schema version 2. Earlier schema-1 session files remain
  readable and use default appearance settings.
- Sessions retain applied strain results; CPU worker settings and the complete
  previous strain-search candidate list are not stored. PNG export remains
  separate from session saving.

## Install or upgrade

```bash
python -m pip install --upgrade "dichromatic-map[gui]==0.1.3"
python -m dichromatic_map --workers 4
```

For numerical calculations without the viewer:

```bash
python -m pip install --upgrade "dichromatic-map==0.1.3"
```

## Downloads

- `dichromatic_map-0.1.3-py3-none-any.whl`: Python wheel for installation with pip.
- `dichromatic_map-0.1.3.tar.gz`: source distribution with documentation and tests.

To install the downloaded wheel with GUI dependencies, run from its download
directory:

```bash
python -m pip install --upgrade "./dichromatic_map-0.1.3-py3-none-any.whl[gui]"
```
