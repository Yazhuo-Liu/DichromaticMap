# DichromaticMap v0.2.2

DichromaticMap 0.2.2 adds symmetry-assisted common-cell selection and portable
desktop applications that include Python and the viewer's dependencies.

## Common-cell selection

- After picking the first edge, use **Complete by symmetry…** to preview
  compatible completions. Symmetries are checked against both grain lattices;
  operations that exchange G1 and G2 are supported.
- After three perimeter vertices, use **Complete parallelogram…** to obtain
  the fourth vertex. Both features work with exact CSL and local near pairs;
  exact CSL completion does not require enabling Near-CSL.
- Inspect the original atom vertices, per-grain atom counts and areas, pair
  separations, principal strain and polar rotations before accepting a candidate.
  Preview axes use equal scales. All vertices use circles; `(auto)` labels
  identify the generated vertices.
- Generated vertices are not limited by the local pair-distance cutoff. They
  must form valid lattice cells and pass the selected strain and rotation limits.
  Completion preserves the original coordinates; apply strain separately when
  needed. Exact CSL cells require no strain.
- Adjust **Local pair distance** while picking vertices without losing the
  existing selection or leaving picking mode.

Symmetry completion is available before bulk strain is applied. It does not
guarantee a primitive cell or enumerate all possible second edges. If the chosen
edge has no independent symmetry-related edge, pick a third vertex and use
parallelogram completion.

## Compatibility

- The Python package continues to support Python 3.10 and later.
- New `.dmap` sessions use schema 4 to retain generated-vertex provenance.
  Schemas 1, 2 and 3 remain readable. Open schema-4 sessions with v0.2.2 or later.
- Existing distance-based local matching and scientific defaults are unchanged.

## Install or upgrade

```bash
python -m pip install --upgrade "dichromatic-map[gui]==0.2.2"
python -m dichromatic_map
```

For numerical calculations without the viewer:

```bash
python -m pip install --upgrade "dichromatic-map==0.2.2"
```

Portable archives include Python, NumPy, PySide6 and PyQtGraph. Keep the entire
extracted directory together. They are built and smoke-tested on Ubuntu 22.04,
Windows 2022 and macOS 15; older operating systems are not validated. Linux still
requires system graphics libraries. Windows/macOS downloads have no publisher
certificate, and macOS apps are not notarized. On macOS, if you trust the archive
downloaded from this project's Releases, try opening `DichromaticMap.app` once,
then choose **System Settings → Privacy & Security → Open Anyway** and confirm
**Open**. Do not override a warning that the app is damaged or will harm your
Mac. See [Apple's instructions](https://support.apple.com/en-us/102445). If your
organization does not permit the app, use the Python package or build from
source. The included `README.txt` has the same first-launch guidance.
