# DichromaticMap v0.1.2

This patch release fixes viewer startup in environments with multiple Qt
Python bindings installed, including Anaconda environments on Windows.

## Fixes

- The viewer and PyQtGraph now consistently use PySide6. This prevents the
  `QMainWindow.setCentralWidget(PlotWidget)` type error caused by mixing Qt
  bindings and removes the need to set `PYQTGRAPH_QT_LIB` manually for normal
  command-line launches.
- If an existing Python session has already loaded PyQtGraph with an
  incompatible binding, the viewer reports how to restart it in a fresh
  process.

## Upgrade

Install or upgrade the library with its viewer:

```bash
python -m pip install --upgrade "dichromatic-map[gui]"
python -m dichromatic_map --workers 4
```

For numerical calculations only:

```bash
python -m pip install --upgrade dichromatic-map
```

Python 3.10 or later is required. The viewer uses PySide6 and PyQtGraph.

## Downloads

- `dichromatic_map-0.1.2-py3-none-any.whl`: Python wheel for installation with pip.
- `dichromatic_map-0.1.2.tar.gz`: source distribution, including documentation
  and tests.

To install the downloaded wheel with GUI dependencies, run this command from
its download directory:

```bash
python -m pip install --upgrade "./dichromatic_map-0.1.2-py3-none-any.whl[gui]"
```
