# DichromaticMap v0.2.1

DichromaticMap 0.2.1 adds a citation reminder to the interactive viewer and
places the recommended citation near the top of the project documentation.

## Improvements

- Closing an interactive GUI window now displays a one-time thank-you message
  with the recommended citation and a clickable DOI link.
- The citation is shown before the viewer finishes closing and releases its
  calculation resources.
- The project README and English and Chinese user guides now display the
  recommended citation near the top of each document.
- Command-line `--save` export remains unattended and exits without opening
  the citation dialog. Terminal signal handling is unchanged.

## Recommended citation

K.Q. Ding, Y.Z. Liu, Y. Zhang, L.H. Wang, X.D. Han, T. Zhu,
“Misfit-dislocation hierarchy governs sliding of asymmetric non-CSL grain
boundaries,” *arXiv preprint* arXiv:2609.14673 (2026).
[https://doi.org/10.48550/arXiv.2609.14673](https://doi.org/10.48550/arXiv.2609.14673)

## Compatibility

- Python 3.10 or later is required.
- There are no changes to numerical algorithms, file formats, session schema,
  command-line options or scientific defaults in this release.
- Existing v0.2.0 sessions remain fully compatible.

## Install or upgrade

```bash
python -m pip install --upgrade "dichromatic-map[gui]==0.2.1"
python -m dichromatic_map --workers 4
```

For numerical calculations without the viewer:

```bash
python -m pip install --upgrade "dichromatic-map==0.2.1"
```

## Downloads

- `dichromatic_map-0.2.1-py3-none-any.whl`: Python wheel for installation with pip.
- `dichromatic_map-0.2.1.tar.gz`: source distribution with documentation and tests.

To install the downloaded wheel with GUI dependencies, run from its download
directory:

```bash
python -m pip install --upgrade "./dichromatic_map-0.2.1-py3-none-any.whl[gui]"
```
