# DichromaticMap v0.2.0

DichromaticMap 0.2.0 adds per-layer marker sizes and clean, atom-only PNG
export, and increases the default local near-CSL matching distance to 0.1 a₀.

## New features

- **Per-layer marker sizes:** open `VIEW / PERFORMANCE → APPEARANCE` and
  adjust each layer's `Size` from **25% to 400%**. The default **100%** keeps
  the existing marker diameter. Both grains share the layer's size setting;
  related CSL, local-pair and manual-cell vertex markers scale with it.
- **Persistent size preferences:** sizes are retained in saved sessions and
  PNG exports. Changing a layer's symbol keeps its size; changing geometry
  preserves settings for retained layers and gives new layers the defaults.
  `Reset appearance` restores the original colors, symbols and sizes.
- **Clean PNG export:** check `Clean PNG (atoms only)` above `Export PNG…`
  to export just the visible G1/G2 atom symbols. The image retains the current
  view, display rotation, grain/layer and GB-side filters, colors, symbols,
  sizes and background. It omits legends, reference axes, readouts, titles,
  coordinate axes, grids, borders and analysis overlays. The option is off
  by default; ordinary annotated export remains available.

## Improvements

- Local near-CSL matching now defaults to **0.1 a₀** instead of 0.05 a₀,
  both in the viewer and when calling `local_near_pairs` without a distance.
- Large markers stay within their legend sample areas, keeping labels readable.
- Size controls fit narrow panels and remain accessible for custom axes with
  many layers.
- PNG export reports write failures. Clean export uses a separate rendering
  scene, leaving the live plot and selections unchanged even if export fails.
- Updated English and Chinese documentation and expanded regression coverage.

## Compatibility and defaults

- Python **3.10 or later** is required. The viewer uses PySide6 and PyQtGraph;
  numerical use requires NumPy. The license remains MIT.
- The larger default matching distance can include additional local pairs.
  Set `Local pair distance` or pass `distance=0.05` to retain the previous
  cutoff. Saved sessions keep their stored cutoff. Exact-CSL tolerance and
  bulk-strain defaults are unchanged.
- New `.dmap` files use **session schema 3** to store marker sizes. Schema-1
  and schema-2 sessions remain readable, with sizes set to 100%; schema-1
  sessions also receive default colors and symbols. New schema-3 files need
  a reader that supports schema 3, such as this release.
- The clean-export checkbox is a PNG export preference and is not stored in
  `.dmap` files. Both PNG export modes produce images 1800 pixels wide.

## Install or upgrade

```bash
python -m pip install --upgrade "dichromatic-map[gui]==0.2.0"
python -m dichromatic_map --workers 4
```

For numerical calculations without the viewer:

```bash
python -m pip install --upgrade "dichromatic-map==0.2.0"
```

## Downloads

- `dichromatic_map-0.2.0-py3-none-any.whl`: Python wheel for installation with pip.
- `dichromatic_map-0.2.0.tar.gz`: source distribution with documentation and tests.
